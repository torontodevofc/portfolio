# ⚡ Portfólio de Yuri (torontodev)

> **"Desenvolvedor de 13 anos explorando games, robótica e o futuro do código."**

Portfólio moderno, veloz e responsivo desenvolvido em **React**, **Tailwind CSS** e **Lucide Icons**, construído com as diretrizes de design e padrões anti-slop da **`taste-skill`**.

---

## 🛠️ Tecnologias Utilizadas

- **Framework:** React 18 + Vite
- **Estilização:** Tailwind CSS (Paleta técnica em cinza e azul, degradês sutis e micro-interações)
- **Tipografia:** Plus Jakarta Sans + JetBrains Mono
- **Ícones:** Lucide React
- **Padrões de Design:** Diretrizes anti-slop de alta fidelidade (Taste Skill)

---

## 🚀 Como Executar Localmente

No seu terminal, dentro da pasta do projeto:

```bash
# 1. Entrar na pasta (caso não esteja nela)
cd C:\Users\yurik\portfolio

# 2. Iniciar o servidor de desenvolvimento
npm run dev
```

Abra o seu navegador e acesse: [http://localhost:5173](http://localhost:5173)

---

## 📦 Como Gerar a Versão de Produção

```bash
npm run build
```

Os arquivos otimizados prontos para deploy (Vercel, Netlify ou GitHub Pages) serão gerados na pasta `dist/`.
